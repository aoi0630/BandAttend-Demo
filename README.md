# BandAttend Demo

BandAttendは、吹奏楽部の予定・出欠・承認・連絡・分析を一つにまとめるWebシステムです。

応募用の作品コンセプト、内容、制作過程、制作環境、応募者の連絡先は、[BandAttend 作品説明（テキスト）](BandAttend_作品説明.txt)にまとめています。

## デモサイト

[BandAttend ポートフォリオデモ](https://bandattend-portfolio-demo.vercel.app)

デモ環境の氏名、予定、出欠、申請理由はすべて架空のデータです。本番環境の部員情報は含まれていません。

### デモの利用方法

ログイン画面で、一般部員、パートリーダー、部長、副部長、先生、管理者から確認したい役割を選択してください。デモ版ではID・パスワードを入力せずに、各役割の画面を体験できます。

この選択式ログインは作品審査用デモだけの機能です。実際の運用では、部員本人のログインID（学籍番号）とパスワードの入力が必要です。デモ用アカウントは閲覧専用で、登録、編集、承認、削除などの更新操作はAPI側で禁止しています。

## 主な機能

- 練習・本番予定のカレンダー表示
- 出席、欠席、遅刻、早退の申請
- パートリーダー、部長、副部長による承認
- 役割に応じた画面と閲覧範囲
- お知らせ、To Do、パート連絡
- 部員別・パート別の出席分析
- スマートフォンとパソコンに対応した画面

## 技術構成

- フロントエンド: Next.js / React
- API: FastAPI
- データベース: SQLite / Turso
- 公開環境: Vercel

## デモデータ

`BANDATTEND_DEMO_DATABASE=1`を設定した環境では、API起動時にデモ専用データベースを初期化し、架空の部員・予定・出欠データを作成します。

セットアップ時は`scripts/setup_portfolio_demo.py`と各`.env.example`を参照してください。

## 注意事項

- このリポジトリは作品紹介・審査用のデモ版です。
- 実在する部員の個人情報や本番データベースは含みません。
- `.env`や認証トークンはリポジトリへ登録しないでください。
